= WTF (Wild Template Fuckery)

WTF is Alibaba's cavern for cursed Lisp.

It's a monorepo for my Common Lisp experiments: interpreters, macros, metaprogramming, compilers, language ideas, and whatever else I end up making.

Nothing here is particularly serious. Some things might be useful. Most probably aren't.
